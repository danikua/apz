## Короткі теоретичні відомості

AWS EC2 (Elastic Compute Cloud) - це сервіс Amazon, що надає віртуальні машини в хмарі, по суті оренду комп'ютерів з керуванням через інтернет. Основні поняття: **Instance** - сама віртуальна машина із заданими характеристиками (vCPU, RAM, сховище, ОС); **AMI** - готовий шаблон операційної системи; **Security Group** - віртуальний фаєрвол, що дозволяє чи забороняє мережевий трафік; **EBS** - постійний диск, дані на якому зберігаються навіть після зупинки машини.

## Контрольні питання

**1. Яка різниця між «Stop» та «Terminate»?**
Stop зупиняє машину, але зберігає її та диск EBS - можна знову запустити, дані лишаються (платиш лише за сховище). Terminate повністю видаляє машину і за замовчуванням її диск, відновити вже не можна.

**2. Чим відрізняються On-Demand, Reserved та Spot інстанси?**
On-Demand - оплата за фактичний час без зобов'язань, найдорожчий, для нерегулярних задач. Reserved - резервування на 1-3 роки зі знижкою, для постійних навантажень. Spot - вільні потужності AWS з великою знижкою, але їх можуть забрати будь-коли, для задач, стійких до переривань.

**3. Навіщо потрібен Security Group?**
Це віртуальний фаєрвол машини: визначає, який вхідний і вихідний трафік дозволено (наприклад, RDP 3389, SSH 22, HTTP 80), і захищає інстанс від небажаних підключень.

**4. Що таке «Region» в AWS?**
Це географічний регіон із центрами обробки даних AWS (наприклад, Europe (Frankfurt), US East (N. Virginia)). Ближчий регіон дає меншу затримку; набір ресурсів і ціни залежать від регіону.

**5. Як підключитися до Windows-інстансу?**
По протоколу RDP: отримати Public IP і розшифрувати пароль адміністратора (Get Windows password + файл `.pem`), відкрити `mstsc`, ввести IP, логін Administrator і пароль.
